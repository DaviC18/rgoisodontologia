# RGóis Odontologia: site

Landing page single-page do consultório RGóis (Barra Mansa, RJ).
Vite + React 19 + TypeScript + Tailwind v4 + GSAP + Lenis.

Antes de mexer, leia `AGENTS.md`, `docs/SPEC.md` e `docs/PLAN.md`.
Todo texto do site fica em `src/content/site.ts`.

## Comandos

- `npm run dev`: desenvolvimento (`?demo=<nome>` abre `src/**/_demo-<nome>.tsx`)
- `npm run build`: checagem de tipos + build de produção
- `npm run preview`: serve o build
- `npm run lint`: ESLint
